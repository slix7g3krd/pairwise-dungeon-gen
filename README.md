# pairwise-dungeon-gen

程序化地牢在固定种子下每次生成都不一样，随机数在并行房间生成时共享了全局状态；房间放置只查中心点距离，旋转后的长条房互相穿插；走廊用直线连接，遇到已占用格直接放弃导致部分房间孤立；死路清理把必经的钥匙房删掉，主线无法通关；难度曲线按房间序号分配，玩家绕路后突然遇到后期精英；钥匙与门的前后关系没校验，出现门在钥匙之前的死锁；导航网格在门洞处没挖开，AI 卡在走廊口；多层地牢的楼梯只连上一层，掉落后无法返回；异步生成在玩家已进入时还在写 tile，脚下地板闪变；存档只保存种子，版本更新后同一 seed 生成不同布局。gameplay/dungeon_generation.py 是核心，tests/test_dungeon_generation.py 15个红。要修的是：每个房间独立 RNG；放置做完整包围盒相交；走廊保证全图连通；死路清理保护关键路径；难度按可达深度分配；钥匙门做拓扑校验；门洞同步挖 navmesh；楼梯双向连接；生成完成再放玩家；存档存布局摘要。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
